# Contradiction and Deprecation Register

Reviewed 2026-10-15. Exact affected locations and source IDs are in the claim ledger.

| Historical doctrine | Disposition | Current boundary |
|---|---|---|
| Fixed local-ranking weights, category weights, traffic shares, or review thresholds | unsupported | Google publishes relevance, distance, and prominence/popularity without weights or guarantees. |
| Fixed PageRank point arithmetic, placement weights, or first-link rules | unsupported | Evolved link-analysis systems are one part of ranking; no public arithmetic supports the model. |
| Mandatory Core 30, word counts, keyword density, link counts, or publishing cadence | practitioner/deprecated | Use as optional planning heuristics only; Google publishes no preferred universal counts. |
| PBN validation, paid insertions, automated comments, or fixed anchor mixes | deprecated | Reject as link spam or high-risk manipulation. |
| Hidden accordions are automatically spam | deprecated | User-facing tabs and accordions are allowed; manipulative hidden text is spam. |
| Show an SAB address or acquire an office for proximity | deprecated/unsafe | Hide a non-customer-facing address; virtual offices are ineligible; coworking storefront rules are strict. |
| Stage a magnet or display a driver’s license in verification video | deprecated/unsafe | Use authentic, non-sensitive evidence only; no faces, identity documents, or staged identity. |
| Twice-weekly GBP posts, 30-day ranking decay, weekly photos, or 24-hour replies | unsupported | Official docs describe features and moderation, not universal ranking cadence. |
| Q&A universally disappeared and Ask Maps replaced it | contested | The API sunset is accepted; consumer/UI availability and Ask Maps rollout remain separately scoped. |
| JSON-LD is the only supported format | deprecated | JSON-LD, Microdata, and RDFa are supported. |
| Own-business AggregateRating produces stars | deprecated | Self-serving LocalBusiness/Organization reviews are ineligible. |
| FAQ/HowTo markup is a current ordinary rich-result or AIO tactic | deprecated | FAQ rich results ended 2026-05-07; no special AIO schema requirement is documented. |
| Schema directly lifts ranking or AI citations | unsupported | It provides vocabulary/feature eligibility; no direct causal guarantee is documented. |
| Reddit has a fixed citation share or is mandatory for LLM visibility | unsupported | Platform/query/date-specific measurement is required. |
| GPS EXIF or geotagging boosts rankings | unsupported | EXIF is a metadata standard; no reviewed ranking evidence supports the tactic. |
| AI detector gaming through errors or fake anecdotes | deprecated/unsafe | Improve clarity and sourcing; never invent human cues or experience. |
| Fabricated Reddit residents, costs, experiences, awards, or guarantees | deprecated/unsafe | Facts-only prompts with disclosed affiliation and human approval. |

| Search review disclosure means Maps incentives are allowed | deprecated/unsafe | Search markup disclosure is a separate rule. Maps prohibits incentivized reviews. |
| EEA aggregator/supplier units are worldwide AI Search features | unsupported | These documented local-business Search units have EEA and provider-participation boundaries. |
