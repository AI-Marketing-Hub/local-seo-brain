# Local Ranking, Structured Data, and AI Feature Boundaries

## Distilled doctrine

Google describes local results using relevance, distance, and prominence/popularity without publishing universal weights. Structured data can be expressed as JSON-LD, Microdata, or RDFa and does not guarantee a rich result.

Google documents no special mandatory schema, AI text file, or separate technical requirement for AI Overviews or AI Mode beyond ordinary Search eligibility and policy. Search Console generative-AI reporting is documented worldwide. The reviewed report provides impressions; dedicated AI-feature clicks or query dimensions are not established.
