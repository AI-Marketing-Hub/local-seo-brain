# Security Policy

Report suspected credential exposure, path traversal, unsafe overwrite behavior, private-data leakage, or transaction integrity failures privately to the repository owner. Do not include live credentials, client exports, reviewer identity, or exploit payloads in a public issue.

Until a private reporting address is published, contact the owner through the private AI Marketing Hub support channel associated with your license and label the message `Local SEO Brain security`.

The supported review candidate is 0.3.0. Security fixes do not authorize publication; they must pass the complete release checklist.
