# Contributing

This is a source-available proprietary repository. Contributions require authorized access and do not change the license.

1. Read `AGENTS.md`, the product boundaries, and safety gates.
2. Create a scoped branch and preserve unrelated work.
3. Update canonical ledgers and overlays before changing generated evidence-bearing content.
4. Use hash-bound Claude Obsidian transactions for canonical template-vault changes.
5. Keep tests in temporary directories and pin every build date.
6. Run every command in `RELEASE_CHECKLIST.md`.
7. Do not include credentials, client data, reviewer identity, unlicensed source payloads, or unsupported marketing claims.

Publication and live-account mutation require separate owner authorization.
