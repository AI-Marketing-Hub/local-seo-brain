# Opening Local SEO Brain in Obsidian

Open `assets/template-brain/` as the working template vault, or open a client vault created by `scripts/scaffold_vault.py`. The repository root is the development workspace and includes scripts, fixtures, sample output, and historical records.

## Open the working vault

1. In Obsidian, choose Open folder as vault.
2. Select `assets/template-brain/` inside the checkout, or the exact generated client folder.
3. Start at `wiki/hot.md`, then `wiki/index.md` and the relevant task hub.

The template contains 59 working chapters, 37 task prompts, six freshness notes, and operating hubs. Its `.obsidian/graph.json` defines 18 tag-based color groups. The `brain` CSS snippet supplies the theme; the generated relationship SVG appears in Overview.

## Check appearance

In Graph View settings, inspect the 18 configured groups and confirm the graph filter scopes to wiki notes. If settings have not reloaded, close and reopen the vault. In Settings, Appearance, CSS snippets, enable `brain` if desired. These are setup checks, not proof of a ranking or maturity result.

## Keep the views separate

The authoritative distributable settings are under `assets/template-brain/.obsidian/`. A root `.obsidian/` folder is an ignored local convenience and is not required or guaranteed to match the template. Avoid opening the repository root when you want a clean client sidebar.

Raw source material and historical extracted images remain private under `.raw/`. Project illustration drafts are retained once in the repository archive. See the vault's Source Manifest Guide for provenance and the dated verification report for actual acceptance results.
