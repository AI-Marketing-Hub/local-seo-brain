# Open Local SEO Research Questions

## Active questions

- How does manual place Q&A availability vary by locale, device, account, and category after the API discontinuation?
- Where is Ask Maps available beyond its documented initial rollout, and which interface states are observable without retaining restricted Places content?
- Which Search Console generative-AI reporting fields are available for each property and date?
- Which local SEO recommendations have reproducible, locale-scoped outcome evidence rather than timing correlations?

## Evidence required

Use bounded, read-only observation with documented sample, locale/device, collection window, raw/auditable results, limitations, sponsor, and independence key. Stop when the budget is exhausted or new sources repeat existing evidence.
