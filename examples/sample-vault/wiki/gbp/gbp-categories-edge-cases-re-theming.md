# GBP Categories Edge Cases (re-Theming)

## Working guidance

Review whether a category still represents the actual business. Do not re-theme a profile to chase queries or add categories for services not offered.

## Use this note

Inputs: The current categories, confirmed business operations, and the reason a category change is proposed.

Result: An accuracy review, unresolved eligibility questions, and an owner-reviewed diff or decision to retain the category.

## Evidence and limits

A Business Profile should use the real-world name and the fewest accurate categories needed to describe its core business; fixed category quotas are not official doctrine. (Claim: gbp-name-and-categories; sources: google-gbp-representation-guidelines, google-gbp-categories.)
