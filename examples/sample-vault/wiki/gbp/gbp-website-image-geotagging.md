## Working guidance

Improve image context, alt text, quality, and performance from actual page evidence. Treat GPS metadata as metadata, not a proven local-ranking tactic.

## Use this note

Inputs: The actual images and page context, alt text, dimensions/performance observations, and any relevant metadata.

Result: Evidence-backed image/context repairs and metadata observations, without treating GPS tags as a proven ranking lever.

## Evidence and limits

EXIF can represent image metadata, including GPS data, but no reviewed source establishes that GPS geotagging causes Google local or organic ranking gains. (Claim: exif-ranking-unsupported; contrary evidence: cipa-exif-31, google-image-seo, google-image-metadata.)
