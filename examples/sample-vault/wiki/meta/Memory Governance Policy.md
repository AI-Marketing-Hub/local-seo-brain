# Memory Governance Policy

## Operating contract

The claim and source ledgers control current evidence. Generated chapters and prompts are corrected through the canonical overlay. Historical raw files remain byte-identical. A confidence tag never substitutes for a source, assessment, or refresh date.

Canonical vault mutations use reviewed, hash-bound transactions. Every created page joins an active index in the same operation.
