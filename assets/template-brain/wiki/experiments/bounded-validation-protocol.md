# Bounded Validation Protocol

## Purpose

Test a scoped local SEO observation without mutating an account or converting correlation into causality.

## Required design

- one falsifiable question and predeclared scope
- sample, query set, locale, device, collection window, and provider settings
- read-only data collection and compliant retention
- documented confounders, missing values, sponsor, and independence key
- a stop condition and explicit no-result outcome

## Output

Record measured observations, limitations, and whether the claim remains provisional, contested, unsupported, or is ready for ledger review. Never promote a single client or screenshot into a universal rule.
