# Observed Query Inventory

> Draft prompt for [[keyword-research|Keyword Research]]. Use only authorized evidence and review the result before external use.

## Evidence status

- Assessment: **provisional**

## Task

Deduplicate observed queries, identify the task each expresses, and separate measured terms from brainstorming. Do not invent volume, competition, landmarks, or rankings.

## Required inputs

Supplied query sources, confirmed offerings and service area, locale, device, and collection dates.

## Output and acceptance

Query/source/date/scope/intent table plus clearly labeled unmeasured hypotheses.

Tie factual assertions to supplied source IDs and locators. Retain needs_input for missing facts. The operator reviews scope, factual support, and privacy; any proposed external change needs owner approval and rollback.
