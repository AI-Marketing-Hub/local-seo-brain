# Start Here

## Before client work

Check freshness for the actual review date and read [[Hot]], [[Dashboard]], and [[Claim Ledger]]. Confirm the client, owner, location model, and privacy boundary. Supply authorized evidence; leave missing inputs explicit.

## Working sequence

1. Use [[Source Intake Workflow]] with explicit targets and a pinned build date.
2. Inspect source receipts and stored hashes.
3. Read current working guidance through [[Index]]. Original lessons remain only in raw provenance.
4. Produce Draft outputs through [[Synthesis Workflow]].
5. Put proposed external changes in [[Approval Queue]] with sources, scope, owner approval, and rollback.

## Maintenance

Use [[Evidence Refresh Flow]] when evidence is due. Generated notes come from canonical overlays and ledgers. Stage changes, inspect the hash-bound transaction, and apply only its reviewed paths.
